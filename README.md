# Anggi's Sweetest Corner 🌸

Sebuah web interaktif spesial dan penuh kasih sayang untuk **Anggi Anisa Lintang** dari **Abg**.  
Dibuat sebagai ruang penyemangat untuk menemani Anggi belajar, persiapan ujian, menyelesaikan tugas, dan menghafal, serta menyambut momen pertemuan pertama kita nanti! ✨

## 🌟 Fitur Utama
- **Gate Screen Interaktif**: Layar pembuka kado romantis dengan foto Anggi berbingkai pastel lavender dan taburan confetti bunga.
- **Hero Showcase & Filmstrip Widget**: Galeri bergerak menampilkan foto dan video favorit Anggi.
- **Love Meter (Suporter Belajar #1)**: Pengukur cinta dan dukungan virtual interaktif hingga 1000%.
- **Koleksi Photocard Anggi**: 10 kartu foto dan video kenangan manis dengan efek bolak-balik (*flip card*).
- **Penyemangat Ujian, Tugas & Hapalan**: 4 kartu motivasi belajar dan kapsul penyemangat interaktif harian.
- **Voucher & Janji Abg**: Tiket resmi voucher coklat dan teman call/peluk virtual LDR yang dapat diunduh sebagai gambar PNG beresolusi tinggi.
- **Audio Romantis**: Musik latar *Peak of Love* yang mengalun lembut.

## 🛠️ Teknologi
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Custom Soft Lavender, Pastel Plum & Sakura Blossom Palette)
- **Animasi & Interaksi**: Framer Motion & Canvas Confetti
- **Deployment**: GitHub Pages (via GitHub Actions)
